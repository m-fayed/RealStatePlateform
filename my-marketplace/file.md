منصة التسويق العقاري الموثوق في مصر

الإصدار النهائي  •  2026
سري — للاستخدام الداخلي فقط


١. نظرة عامة على المنتج
منصة ويب متخصصة في التسويق العقاري الموثوق في مصر. تربط المسوقين العقاريين المرخصين رسمياً بالباحثين عن عقارات بطريقة آمنة وشفافة. الميزة الجوهرية هي أن كل مسوق على المنصة يحمل رخصة رسمية من الدولة، وكل إعلان مربوط برخصة إعلان — مما يقضي على الإعلانات الوهمية والمسوقين غير الموثوقين.

المشكلة التي تحلها المنصة
●	الإعلانات الوهمية منتشرة في OLX وFacebook — عقارات غير موجودة أو مباعة مسبقاً
●	مسوقون غير مرخصين يعملون بدون أي توثيق رسمي
●	نفس العقار يُعرض بأسعار مختلفة من مسوقين متعددين
●	صعوبة التحقق من هوية المسوق أو صحة الإعلان

الحل
"المنصة الوحيدة في مصر التي تضمن أن كل مسوق موثق رسمياً وكل إعلان مربوط برخصة حكومية"


٢. المستخدمون
المنصة تخدم نوعين أساسيين من المستخدمين، بالإضافة لزائر بدون تسجيل:

النوع	طريقة التسجيل	الصلاحيات الكاملة
🏠 المسوق العقاري	رخصة تسويق + رخصة إعلان رسمية	رفع إعلانات — بروفايل خاص — استقبال استفسارات
🔍 الباحث	رقم موبايل فقط	تصفح عقارات — التواصل مع المسوقين
👁️ الزائر (بدون تسجيل)	لا يوجد	تصفح الإعلانات فقط — بدون تواصل


 
٣. الـ Features بالتفصيل
فيما يلي شرح كامل لكل feature في المنصة من منظور الكود والمنطق التقني:

٣.١ — نظام التسجيل والمصادقة (Authentication)
وصف الـ Feature
أول شاشة في التطبيق. اليوزر يختار نوع حسابه ويكمل التسجيل بناءً على نوعه. كل نوع له مسار تسجيل مختلف.
مسار المسوق العقاري
●	يدخل الاسم — رقم الموبايل — البريد الإلكتروني — كلمة السر
●	يرفع صورة رخصة التسويق الصادرة من الهيئة العامة للرقابة على الصادرات والواردات
●	يرفع صورة رخصة الإعلان المرتبطة بالعقار
●	الحساب يبقى في حالة (Pending) لحين مراجعة الرخصة يدوياً من الـ Admin
●	بعد الموافقة يتفعل الحساب ويقدر يبدأ ينشر
مسار الباحث
●	يدخل رقم الموبايل
●	يستقبل OTP (كود تحقق) على الموبايل
●	يكمل اسمه وكلمة السر
●	الحساب يتفعل فوراً بدون مراجعة
الـ Admin Panel — مراجعة المسوقين
●	لوحة تحكم للـ Admin يشوف فيها طلبات التسجيل الجديدة
●	يراجع صور الرخص
●	يوافق أو يرفض مع كتابة السبب
●	المسوق يستلم إشعار بالنتيجة
البيانات المخزنة (Database)
الحقل	النوع	الوصف
id	UUID	معرف فريد لكل مستخدم
name	String	الاسم الكامل
phone	String	رقم الموبايل — مميز لكل حساب
email	String	البريد الإلكتروني (اختياري للباحث)
password	String (Hashed)	كلمة السر مشفرة
role	Enum	broker (مسوق) / seeker (باحث)
status	Enum	pending / active / rejected / suspended
license_image	String (URL)	رابط صورة رخصة التسويق
ad_license	String	رقم رخصة الإعلان
created_at	Timestamp	تاريخ التسجيل
الفائدة
طبقة ثقة حقيقية — مستحيل وجود مسوق وهمي على المنصة. الـ Admin هو الضامن.


٣.٢ — نظام الإعلانات العقارية (Listings)
وصف الـ Feature
القلب الأساسي للمنصة. المسوق يرفع إعلانات عقارية، والباحث والزائر يتصفحونها.
إنشاء إعلان جديد — من جهة المسوق
●	المسوق يضغط 'إضافة إعلان' من الـ Dashboard بتاعه
●	يختار نوع العقار من القائمة
●	يختار نوع العرض (للبيع أو للإيجار)
●	يدخل بيانات العقار التفصيلية
●	يرفع صور العقار (حد أقصى 10 صور)
●	يضغط نشر — الإعلان يظهر فوراً في الصفحة العامة

أنواع العقارات المتاحة
القسم	الأنواع
🏘️ سكني	شقة — فيلا — دوبلكس — بنتهاوس — استوديو
🏢 تجاري	محل — مكتب — عيادة — مخزن
🌍 أراضي	أرض سكنية — أرض تجارية — أرض زراعية

بيانات كل إعلان (Database)
الحقل	النوع	الوصف
id	UUID	معرف فريد للإعلان
broker_id	UUID (FK)	مرتبط بحساب المسوق
title	String	عنوان الإعلان
property_type	Enum	نوع العقار (شقة، فيلا، محل...)
offer_type	Enum	للبيع / للإيجار

city	String	المدينة

الفائدة
كل إعلان مربوط برخصة إعلان رسمية — لا يمكن للمسوق نشر إعلان بدون رقم رخصة. ده الفارق الجوهري عن OLX.


 
٣.٣ — صفحة التصفح والفلاتر (Browse & Filters)
وصف الـ Feature
الصفحة الرئيسية للمنصة. بتعرض كل الإعلانات النشطة بشكل Grid أو List، مع فلاتر تساعد المستخدم يلاقي اللي يدور عليه بسرعة.
شكل الكارت في الصفحة
●	صورة رئيسية للعقار
●	اسم المسوق وصورته
●	نوع العقار + نوع العرض (للبيع / للإيجار)
●	السعر
●	المدينة والمنطقة
●	وقت النشر (منذ 3 ساعات، منذ يوم...)
●	زر 'التواصل مع المسوق'
الفلاتر المتاحة
الفلتر	القيم المتاحة	ملاحظة
نوع العقار	شقة / فيلا / محل / مكتب / أرض...	اختيار واحد أو أكثر
نوع العرض	للبيع / للإيجار	اختيار واحد
المدينة	القاهرة / الإسكندرية / الجيزة...	اختيار واحد
نطاق السعر	من ___ إلى ___	رقم يدوي
الترتيب	الأحدث / الأقل سعراً / الأعلى سعراً	اختيار واحد
الـ API Endpoint
GET /api/listings?type=apartment&offer=sale&city=cairo&min_price=500000&max_price=2000000&sort=newest
الفائدة
الباحث يوصل لعقاره في أقل من دقيقة بدل ما يتوه في آلاف الإعلانات.


٣.٤ — بروفايل المسوق (Broker Profile)
وصف الـ Feature
صفحة خاصة لكل مسوق. أي زائر أو باحث يقدر يدخل عليها ويشوف كل معلومات المسوق وكل إعلاناته في مكان واحد.
محتوى صفحة البروفايل
●	اسم المسوق وصورته الشخصية
●	رقم رخصة التسويق (ظاهر للعلن لإثبات المصداقية)
●	تاريخ الانضمام للمنصة
●	عدد الإعلانات النشطة
●	كل الإعلانات العقارية الخاصة بيه
●	زر 'تواصل معي' (متاح بعد تسجيل دخول الباحث)
الفائدة
المسوق الجيد يبني سمعة حقيقية على المنصة مع الوقت. الباحث يقدر يشوف تاريخ المسوق ويتطمن قبل ما يتواصل.


٣.٥ — نظام التواصل (Chat / Contact)
وصف الـ Feature
التواصل المباشر بين الباحث والمسوق. بيحصل بعد ما الباحث يسجل دخوله ويضغط 'تواصل' على أي إعلان.
آلية التواصل — مرحلتين
المرحلة الأولى (MVP): تحويل لواتساب
●	الباحث يضغط 'تواصل مع المسوق'
●	لو مش مسجل — بيطلب منه التسجيل الأول
●	بعد التسجيل — بيفتحله واتساب المسوق مباشرة بنص جاهز
●	النص الجاهز: 'مرحباً، رأيت إعلانك على منصة [اسم المنصة] عن [نوع العقار] في [المدينة] — هل ما زال متاحاً؟'
●	الفائدة: سريع في التطوير ومش محتاج infrastructure معقدة
المرحلة الثانية (بعد الـ MVP): شات داخلي
●	شات مدمج داخل المنصة
●	الباحث يبعت رسالة للمسوق من داخل التطبيق
●	المسوق يستقبل إشعار بالرسالة الجديدة
●	تاريخ المحادثات محفوظ للطرفين
●	التقنية المقترحة: Firebase Realtime Database أو Socket.io
من يتواصل مع مين؟
المُرسِل	المُستقبِل	مسموح؟
باحث مسجل	مسوق عقاري	✅ أيوه
زائر بدون تسجيل	أي مسوق	❌ لأ — لازم يسجل الأول
مسوق	مسوق آخر	❌ مش مدعوم
الفائدة
التسجيل شرط للتواصل يحمي المسوقين من الاستفسارات العشوائية والسبام ويضمن جودة التواصل.


 
٣.٦ — لوحة تحكم الـ Admin
وصف الـ Feature
واجهة إدارية داخلية يستخدمها فريق المنصة للإشراف على كل شيء. مش ظاهرة للمستخدمين.
الصلاحيات والمهام
●	مراجعة طلبات تسجيل المسوقين الجدد والموافقة أو الرفض
●	مشاهدة كل الإعلانات النشطة وإمكانية حذف أي إعلان مخالف
●	إيقاف أو تعليق أي حساب مسوق عند الإخلال بالشروط
●	متابعة إحصائيات المنصة: عدد المسوقين — عدد الإعلانات — عدد الباحثين
●	استقبال البلاغات من المستخدمين
الفائدة
الـ Admin هو الضامن الأساسي لجودة المنصة — بدونه مفيش فرق بين منصتنا وبين OLX.


٣.٧ — الإشعارات (Notifications)
وصف الـ Feature
إشعارات تُبقي المستخدم على علم بكل ما يحدث في حسابه.
إشعارات المسوق
●	تم قبول طلب التسجيل — حسابك فعّال الآن
●	تم رفض طلب التسجيل مع ذكر السبب
●	باحث جديد تواصل معك (في مرحلة الشات الداخلي)
●	إعلانك وصل لـ X مشاهدة
إشعارات الباحث
●	تم تسجيل حسابك بنجاح
●	رد المسوق على استفساره (في مرحلة الشات الداخلي)
قناة الإشعارات
●	في المرحلة الأولى: SMS أو رسالة واتساب
●	مستقبلاً: Push Notifications لو اتعمل Mobile App


٤. شاشات التطبيق
المنصة Web App Responsive — يشتغل على الموبايل والكمبيوتر بنفس الكفاءة.

#	الشاشة	من يراها؟	الوصف التقني
١	الصفحة الرئيسية	الجميع	تعرض كل الإعلانات النشطة مع الفلاتر — GET /api/listings
٢	صفحة تفاصيل إعلان	الجميع	تفاصيل عقار واحد كاملة — GET /api/listings/:id
٣	بروفايل المسوق	الجميع	معلومات المسوق وكل إعلاناته — GET /api/brokers/:id
٤	التسجيل / تسجيل الدخول	غير مسجلين	مسارات مختلفة للمسوق والباحث — POST /api/auth
٥	الشروط والاتفاقية	عند التسجيل	صفحة ثابتة — تظهر مرة واحدة عند أول تسجيل
٦	Dashboard المسوق	المسوق فقط	إدارة الإعلانات — إضافة — تعديل — حذف
٧	إضافة إعلان جديد	المسوق فقط	فورم رفع بيانات العقار والصور — POST /api/listings
٨	الشات / التواصل	الباحث المسجل	المرحلة الأولى: redirect لواتساب — المرحلة التانية: شات داخلي
٩	Admin Panel	الـ Admin فقط	لوحة تحكم داخلية — مراجعة مسوقين — إدارة المنصة


 
٥. الـ Tech Stack المقترح
اختيارات تقنية مناسبة لفريق صغير مع قابلية للتوسع مستقبلاً:

الطبقة	التقنية	السبب
Frontend	React.js + Tailwind CSS	سريع — مجتمع كبير — Responsive بسهولة
Backend	Node.js + Express	سريع في التطوير — مناسب للـ REST API
Database	PostgreSQL	قوي للبيانات العلاقية — مجاني ومفتوح المصدر
File Storage	Cloudinary أو AWS S3	لرفع وتخزين صور العقارات
Auth	JWT + OTP (Twilio)	JWT للمسوق — OTP برقم موبايل للباحث
Chat (مرحلة ٢)	Firebase Realtime DB	سهل وسريع للشات الـ Real-time
Hosting	Railway أو Render	سهل ورخيص للبداية
SMS / OTP	Twilio أو Vonage	إرسال كود تحقق لرقم الموبايل
