# منصة السوق العقاري — الحالة الحالية

واجهة عربية RTL مبنية باستخدام React 19 وVite 8 وTailwind CSS 4، وخادم Express مع التحقق باستخدام Zod وقاعدة SQLite عبر Prisma 6.

تشمل المنصة تسجيل الباحثين والوسطاء، مراجعة الوسطاء والإعلانات بواسطة المسؤول، تعديل الإعلانات وحالات البيع والتأجير، الرصيد والترويج، المحادثات، ورفع الصور والمستندات الخاصة.

واجهة API تعمل افتراضياً على المنفذ **5002** والواجهة الأمامية على 5173. الدفع عبر Vodafone Cash يحتاج مراجعة المسؤول؛ البطاقة وFawry مجرد محاكاة لا تعمل إلا عند تفعيل إعدادَي التطوير صراحةً. لا يوجد تكامل مع بوابة دفع حقيقية.

للتثبيت والإعداد والمتغيرات البيئية والأوامر راجع [README الحالي](my-marketplace/README.md). راجع أيضاً [API](API_DOCUMENTATION.md) و[المخطط](DATABASE_SCHEMA.md) و[الاختبارات](TESTING_GUIDE.md).

هذه قاعدة تطوير قابلة للاختبار وليست شهادة جاهزية للإنتاج. الملخصات السابقة لا تمثل ضماناً لاكتمال كل متطلبات النشر.
